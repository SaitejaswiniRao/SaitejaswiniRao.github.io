About

This project involves the design and implementation of a 3-DOF robotic manipulator integrated with a Digital Twin system. The robot is designed using Autodesk Fusion 360 and modelled in URDF for simulation and kinematic analysis in MATLAB Robotics Toolbox. An Arduino microcontroller controls the servo motors based on joint angle commands from MATLAB, enabling real-time synchronization between the physical robot and its virtual model. This integration allows robot motion visualization, simulation, and validation in a digital environment.
